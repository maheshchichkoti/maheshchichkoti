## Featured projects

### [News RAG Backend](https://github.com/maheshchichkoti/news-rag-backend)

A FastAPI chatbot that answers questions about news articles. It embeds articles with Jina, retrieves relevant passages from Qdrant, and uses Gemini to generate answers. Redis stores conversation history.

### WorkBridge · [Live demo](https://workbridgee.vercel.app)

A platform where developers can find real projects, submit work, and get feedback. The Next.js frontend uses a Node.js service for authentication and a separate FastAPI service for vector search with PostgreSQL and pgvector.

### [Neo Event System](https://github.com/maheshchichkoti/neo-event-system)

A scheduling API built with FastAPI and PostgreSQL. It supports recurring events and role-based sharing, records who changed each event, and lets users compare or roll back revisions.

### [Email Sequence Builder](https://github.com/maheshchichkoti/email-sequence)

A React Flow editor for designing email sequences with delays between steps. The Express backend schedules sends with Agenda and MongoDB and delivers them with Nodemailer.
